IMPORTANT
This package stores data in the browser on each device (localStorage).
That means Chris can log in on a device where this same app is installed, but changes do NOT automatically sync between separate devices yet.
For true shared live data, the next step is to connect this app to an online database/backend (for example Cloudflare D1 + Worker, Supabase, or Firebase).

DEPLOY
Upload the contents of this folder to your Cloudflare Pages project.
Do not upload the ZIP itself if Cloudflare asks for a folder/build output; unzip first and upload the files inside.

PHOTO NOTE
Work order pictures are stored in IndexedDB on the device/browser. They do not sync to other devices until an online shared backend is connected.
