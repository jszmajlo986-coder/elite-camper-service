ELITE CAMPER SERVICE — CLOUDFLARE PAGES APP

1. Sign in to Cloudflare.
2. Open Workers & Pages.
3. Create a Pages project using Direct Upload.
4. Upload this ZIP file.
5. After deployment, open the Pages project.
6. Choose Custom domains.
7. Add app.elitecamperservice.com.
8. In Wix DNS, add a CNAME:
   Host: app
   Points to: the Cloudflare Pages address shown in your project.
9. Open https://app.elitecamperservice.com in Safari.
10. Tap Share > Add to Home Screen.

IMPORTANT:
The current app saves records on the iPad itself. Cloud backup and multi-device syncing require a database connection.
